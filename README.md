# G-Mode-15-Churashima-Life-English-Translation-Patch

Hello, 

These patched files will translate your copy of G-Mode 15 into English, for Nintendo Switch or Steam. 

This was made with machine translation, otherwise work was done by a human. 

Nintendo Switch Installation:

Download GMode15SwitchEnglish.zip and copy the 0100F1C012E5A000 folder into your atmosphere\contents folder of your Switch SD card 

(Alternatively, if using an emulator, navigate to the mod directory for your copy of the game, and copy the 0100F1C012E5A000 folder there, renaming 0100F1C012E5A000 to something else (Rename to English, for example))

Steam Installation:

Download GMode15SteamEnglish.zip, navigate to C:\Program Files (x86)\Steam\steamapps\common\okinawa (default install location), and back up the following files, if you wish:

okinawa_Data\level0
okinawa_Data\Managed\Assembly-CSharp.dll
okinawa_Data\StreamingAssets\file\binary
okinawa_Data\StreamingAssets\file\event
okinawa_Data\StreamingAssets\file\image
okinawa_Data\StreamingAssets\file\image_scene
okinawa_Data\StreamingAssets\file\str
okinawa_Data\StreamingAssets\prefab\appliarchive
okinawa_Data\StreamingAssets\prefab\characterinput
okinawa_Data\StreamingAssets\prefab\debugmenu
okinawa_Data\StreamingAssets\prefab\dialogcommon
okinawa_Data\StreamingAssets\prefab\howtoplay
okinawa_Data\StreamingAssets\prefab\ranking
okinawa_Data\StreamingAssets\prefab\setting
okinawa_Data\StreamingAssets\prefab\title
okinawa_Data\StreamingAssets\prefab\window

Otherwise, copy "okinawa_Data" into the same directory as okinawa.exe and overwrite all files when prompted. 

Any bugs/issues please report to Issues, otherwise enjoy the game!
